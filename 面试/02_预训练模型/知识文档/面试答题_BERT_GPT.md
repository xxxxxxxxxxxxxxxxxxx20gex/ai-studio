## Q1: BERT和GPT的本质区别是什么？

**核心答案：**  
> 「BERT 是基于 Transformer **Encoder** 的双向模型，擅长理解；  
> GPT 是基于 Transformer **Decoder** 的单向自回归模型，擅长生成。」

**详细对比：**

```text
【BERT】 - Bidirectional Encoder

输入: "我 [MASK] 中国"

注意力机制: 双向 (Bidirectional)
┌─────────────────────┐
│  我  ←→  [MASK]  ←→  中国  │  每个词可以看到所有词
└─────────────────────┘

预测: [MASK] = "爱"（根据上下文）
任务: 完形填空 (Masked LM)


【GPT】 - Generative Pre-trained Transformer

输入: "我 爱"

注意力机制: 单向 / 因果 (Causal)
┌─────────────────────┐
│  我  →  爱  →  ???      │  只能看到前文，不能看未来
└─────────────────────┘

预测: 下一个词 = "中国"
任务: 续写 / 生成
```

**实现差异示意：**

```text
# BERT 的 Attention（双向）
     我   爱   中国
我  [✓   ✓   ✓ ]
爱  [✓   ✓   ✓ ]
中国[✓   ✓   ✓ ]

# GPT 的 Masked Attention（单向）
     我   爱   中国
我  [✓   ✗   ✗ ]
爱  [✓   ✓   ✗ ]
中国[✓   ✓   ✓ ]
```

## Q2: 为什么BERT适合理解，GPT适合生成？

### 2.1 BERT 适合理解任务

**原因 1：双向上下文**

```text
句子: "这家银行的利息很高"

BERT 同时看到：
← "这家银行的"  和  "利息很高" →

可以判断这里的 "银行" 是金融机构，而不是河岸（river bank）。
```

**原因 2：预训练目标偏向理解**

```text
MLM 任务: 北京是中国的 [MASK]
→ 需要理解上下文语义，才能填出 "首都"

NSP 任务: 判断两个句子是否连续
→ 需要理解句子间逻辑关系
```

**适用场景：**
- 文本分类（情感分析、主题分类）；
- 命名实体识别（NER）；
- 阅读理解（抽取式 QA）；
- 语义相似度计算等。

### 2.2 GPT 适合生成任务

**原因 1：自回归架构天然适合逐步生成**

```text
生成过程：
输入: "今天天气"
→ 预测下一个词："很好"
→ 继续预测："，适合出门散步"
→ 形成一整句自然语言
```

**原因 2：预训练目标就是「预测下一个词」**

```text
训练时：给定前文，预测下一个 token
P(x_t | x_1, x_2, ..., x_{t-1})

这和生成任务完全对齐。
```

**适用场景：**
- 文本生成、对话系统（ChatGPT）；
- 代码生成（Codex 类模型）；
- 翻译、摘要、写作辅助等。

## Q3: 为什么GPT也能做理解任务？

**答题思路：** 从「规模效应」和「提示学习」角度回答。

**早期 GPT (GPT-1/2)：**

```text
- 模型规模有限（百 M ～ 数 B）
- 做理解任务通常需要微调
- 单向注意力只能看前文，相比 BERT 双向编码有劣势
```

**大规模 GPT (GPT-3/4)：**

```text
通过大规模预训练（海量数据 + 超大参数量），
在很多理解任务上出现「涌现能力」：
- 不微调，仅靠 prompt 就能做分类、推理、翻译
- Few-shot / Zero-shot 效果很强
```

**关键洞察：**

> 「当模型足够大、数据足够多时，GPT 虽然架构上是单向 Decoder-only，但通过前缀提示、少样本学习等方式，依然可以在理解类任务上达到甚至超过 BERT 系模型的效果。」

## Q4: 了解各自的代表模型

### 4.1 BERT 系列

```text
BERT-base (2018):
- 参数: 110M
- 层数: 12
- 隐藏维度: 768

BERT-large (2018):
- 参数: 340M
- 层数: 24
- 隐藏维度: 1024

后续变体：
- RoBERTa: 改进训练策略、去掉 NSP
- ALBERT: 参数共享，大幅减小模型大小
- DeBERTa: 引入相对位置编码和解耦注意力
- ELECTRA: 判别式预训练（样本效率更高）
```

### 4.2 GPT 系列

```text
GPT-1 (2018):
- 提出「预训练 + 微调」范式

GPT-2 (2019):
- 最大 1.5B 参数
- 展示了强大的 Zero-shot 生成能力

GPT-3 (2020):
- 175B 参数
- In-Context Learning / Few-shot Learning 涌现

GPT-3.5 / ChatGPT (2022):
- 在 GPT-3 基础上加入 RLHF 对齐
- 对话能力大幅提升

GPT-4 (2023):
- 多模态（文本 + 图像）
- 推理和安全性进一步增强
```

### 4.3 中文生态中的代表

```text
BERT 系：
- BERT-wwm, MacBERT, RoBERTa-wwm 等

GPT 系：
- CPM, GLM/ChatGLM, 百川 Baichuan, 通义 Qwen 等
```

**加分总结：**

> 「总体趋势上看，早期是 Encoder-only（BERT）+ Decoder-only（GPT）各自负责不同下游任务；  
> 但进入大模型时代后，Decoder-only（GPT 风格）一统天下，配合指令微调和 RLHF，既能理解又能生成，逐渐成为工业界默认范式。」
