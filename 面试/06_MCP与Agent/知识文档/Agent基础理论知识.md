## 一、Agent基本概念 ⭐⭐⭐

### 1. 什么是Agent？

**定义:**
- Agent（智能体）= LLM + 推理能力 + 工具调用 + 记忆
- 能够感知环境、自主决策、执行动作的AI系统

**核心能力:**
- 🧠 推理：分析问题，制定计划
- 🔧 工具使用：调用外部工具完成任务
- 💾 记忆：记住上下文和历史
- 🔄 反思：评估结果，优化策略

### 2. Agent vs LLM

| 特性 | 传统LLM | Agent |
|------|---------|-------|
| 能力范围 | 文本生成 | 自主决策+执行 |
| 工具使用 | 无 | 可调用外部工具 |
| 任务执行 | 一次性回答 | 多步骤规划执行 |
| 反馈循环 | 无 | 可根据结果调整策略 |
| 典型应用 | 问答、写作 | 任务自动化、问题解决 |

### 3. Agent的核心组件

```
┌─────────────────────────────────┐
│         Agent 架构               │
├─────────────────────────────────┤
│  1. 大语言模型 (LLM Core)       │
│     - 推理引擎                   │
│     - 决策中心                   │
│                                 │
│  2. 工具集 (Tools)              │
│     - 搜索引擎                   │
│     - 计算器                     │
│     - API调用                    │
│     - 代码执行                   │
│                                 │
│  3. 记忆系统 (Memory)           │
│     - 短期记忆（对话历史）       │
│     - 长期记忆（知识库）         │
│                                 │
│  4. 规划器 (Planner)            │
│     - 任务分解                   │
│     - 步骤规划                   │

│  5. 执行器 (Executor)           │
```

## 二、推理框架（必考）⭐⭐⭐⭐⭐

### 1. ReAct (Reasoning + Acting) ⭐⭐⭐⭐⭐

**核心思想:** 推理和行动交替进行

**流程:**
```
Thought (思考) → Action (行动) → Observation (观察) 
    ↓                                    ↑
    └────────────────循环─────────────────┘
```

**示例:**
```
Question: 2023年诺贝尔物理学奖得主是谁？

Thought 1: 我需要搜索2023年诺贝尔物理学奖的信息
Action 1: Search["2023年诺贝尔物理学奖得主"]
Observation 1: Pierre Agostini, Ferenc Krausz, Anne L'Huillier

Thought 2: 我找到了答案，是三位科学家
Action 2: Finish["2023年诺贝尔物理学奖得主是..."]
```

**优势:**
- 可解释性强（能看到推理过程）
- 可纠错（观察结果后可调整）
- 适合复杂任务


### 2. Chain-of-Thought (CoT) ⭐⭐⭐⭐⭐

**核心思想:** 让模型逐步推理，展示思考过程

**类型:**

**Zero-shot CoT:**
```
Prompt: "Let's think step by step..."
→ 模型自动分步推理
```

**Few-shot CoT:**
```
提供带推理过程的示例:

Q: 商店有15个苹果，卖了8个，又进了12个，现在有多少？
A: 让我一步步想：
   1. 初始：15个
   2. 卖了8个：15-8=7个
   3. 又进12个：7+12=19个
   答案：19个

Q: [新问题]
A: 让我一步步想：...
```

**应用场景:**
- 数学问题
- 逻辑推理
- 复杂决策


### 3. Tree-of-Thought (ToT) ⭐⭐⭐

**核心思想:** 探索多个推理分支，选择最优路径

**流程:**
```
          问题
        ↙ ↓ ↘
    思路1 思路2 思路3
    ↙↘   ↙↘   ↙↘
   ... (展开成树)

评估每个分支，选择最优路径
```

**适用场景:**
- 需要探索多种可能性
- 创意任务（写作、设计）
- 游戏AI


### 4. ReWOO (Reasoning WithOut Observation) ⭐⭐⭐

**核心思想:** 先规划好所有步骤，再批量执行

**对比ReAct:**
```
ReAct: 思考→行动→观察→思考→行动... (串行)
ReWOO: 思考→规划所有步骤→批量执行 (并行)
```

**优势:**
- 减少LLM调用次数
- 可并行执行工具
- 更高效


### 5. Plan-and-Execute ⭐⭐⭐⭐

**核心思想:** 先制定完整计划，再逐步执行

**流程:**
```
1. Planner: 将任务分解成步骤
2. Executor: 逐步执行
3. Re-plan: 根据结果动态调整
```

**面试重点**
- ✅ 能说出ReAct和CoT的区别
- ✅ 理解各种框架的适用场景
- ✅ 知道ReAct的Thought-Action-Observation循环

## 三、工具调用（高频）⭐⭐⭐⭐⭐

### 1. Function Calling 原理

**什么是Function Calling？**
- LLM 根据用户意图，决定调用哪个工具
- 生成工具调用的参数
- 获取结果后继续推理

**流程:**
```
用户输入
    ↓
LLM理解意图
    ↓
选择合适的工具
    ↓
生成工具参数
    ↓
执行工具调用
    ↓
获取结果
    ↓
LLM整合结果
    ↓
返回最终答案
```

### 2. 工具定义

**Schema定义:**
```json
{
  "name": "get_weather",
  "description": "获取指定城市的天气信息",
  "parameters": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "城市名称，如'北京'"
      },
      "date": {
        "type": "string",
        "description": "日期，格式YYYY-MM-DD"
      }
    },
    "required": ["city"]
  }
}
```

### 3. 工具选择策略

- **单工具**: 简单明确的任务
- **多工具串行**: 需要多步骤，有依赖关系
- **多工具并行**: 独立的多个子任务

### 4. 常见工具类型

- 🔍 搜索工具（Google、Bing、Wikipedia）
- 🧮 计算工具（Calculator、Python REPL）
- 📊 数据库查询（SQL）
- 🌐 API调用（天气、地图、股票）
- 💻 代码执行（Python、JavaScript）

## 四、记忆系统 ⭐⭐⭐⭐

### 1. 短期记忆（Working Memory）

**特点:**
- 保存当前对话历史
- 上下文窗口限制
- 实现：滑动窗口、摘要压缩

**示例:**
```
对话1: "我叫张三"
对话2: "我喜欢AI"
对话3: "我的名字是什么？"

Agent回答: "您的名字是张三"
→ 从短期记忆中检索
```

### 2. 长期记忆（Long-term Memory）

**特点:**
- 持久化存储
- 知识库、向量数据库
- 实现：RAG（检索增强生成）

**类型:**
- **语义记忆**: 事实知识（如"北京是中国首都"）
- **情节记忆**: 历史对话、用户偏好
- **程序记忆**: 学到的技能、工具使用经验

### 3. 向量记忆

**实现:**
```
1. 将记忆转换为向量
2. 存储到向量数据库
3. 根据相似度检索
4. 整合到上下文
```

## 五、Agent架构 ⭐⭐⭐⭐

### 1. 单Agent架构

**基础模式:**
```
Perception (感知) → Planning (规划) → Execution (执行)
```

**实现方式:**
- **Reflexion**: 自我反思，从错误中学习
- **Self-Ask**: 自问自答，逐步分解问题
- **Toolformer**: 自主学习何时使用工具

### 2. 多Agent架构

**协作模式:**
- **主从模式**: 一个管理者Agent + 多个执行Agent
- **平等协作**: 多个Agent讨论协商
- **专家系统**: 不同领域的专家Agent

**通信机制:**
- 共享内存
- 消息传递
- 黑板系统

### 3. Agent循环

```python
while not done:
    # 1. 感知环境
    observation = environment.get_state()
    
    # 2. 推理决策
    thought = agent.think(observation)
    action = agent.decide(thought)
    
    # 3. 执行动作
    result = agent.execute(action)
    
    # 4. 更新记忆
    agent.memory.update(observation, action, result)
    
    # 5. 检查是否完成
    done = agent.is_task_complete()
```

## 六、多Agent协作 ⭐⭐⭐⭐

### 1. 协作模式

**辩论模式 (Debate):**
```
Agent A: 提出观点A
Agent B: 提出观点B
Agent C: 评估并综合
→ 得到更优解
```

**角色分工:**
```
研究员Agent: 收集信息
分析师Agent: 分析数据
写作Agent: 撰写报告
审核Agent: 质量检查
```

### 2. 通信机制

- **直接通信**: Agent之间直接传递消息
- **广播**: 一个Agent向所有Agent发送
- **订阅**: Agent订阅感兴趣的信息

### 3. 应用场景

- 软件开发（设计、编码、测试、review）
- 内容创作（研究、写作、编辑、校对）
- 数据分析（采集、清洗、分析、可视化）
