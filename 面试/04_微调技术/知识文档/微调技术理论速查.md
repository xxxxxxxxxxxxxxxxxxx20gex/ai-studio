# 微调技术理论速查 ⭐⭐⭐⭐⭐

> 💡 参数高效微调（PEFT）是当前大模型应用的核心技术，面试高频考点！

## 1. 微调方法对比

| 方法 | 可训练参数量 | 显存占用 | 训练难度 | 适用场景 |
|------|------------|---------|---------|---------|
| 全量微调 | 100% | 很高 | 中等 | 小模型、充足资源 |
| LoRA | <1% | 低 | 低 | 通用，推荐首选 |
| Adapter | 2-4% | 低 | 低 | 需要更强表达能力 |
| Prompt Tuning | <0.1% | 极低 | 中等 | 超大模型（>10B） |
| Prefix Tuning | <1% | 低 | 中等 | 生成任务 |

---

## 2. LoRA (Low-Rank Adaptation) ⭐⭐⭐⭐⭐

**核心原理:**
- 冻结预训练权重W
- 添加低秩分解矩阵：W' = W + B×A
- 只训练A和B矩阵

**数学表示:**
```
原始: h = W·x
LoRA: h = W·x + (B·A)·x = (W + ΔW)·x

其中:
- W ∈ R^(d×k): 冻结的预训练权重
- A ∈ R^(r×k): 可训练的下投影矩阵
- B ∈ R^(d×r): 可训练的上投影矩阵
- r: 秩（通常r << min(d,k)，如r=8）
```

**参数量对比:**
```
原始参数量: d × k
LoRA参数量: r × (d + k)

示例（d=k=1024, r=8）:
- 原始: 1,048,576 参数
- LoRA: 16,384 参数（减少98.4%）
```

**优点:**
- ✅ 参数极少（通常<1%）
- ✅ 推理时可合并权重，无额外开销
- ✅ 训练稳定，效果好
- ✅ 支持多任务切换（切换A、B矩阵即可）

**缺点:**
- ❌ 低秩假设不一定总是成立
- ❌ rank需要调参

**应用位置:**
- Transformer的Q、K、V投影层
- 输出投影层
- 前馈网络（可选）

---

## 3. Adapter（适配器） ⭐⭐⭐⭐

**核心原理:**
- 在Transformer层之间插入小型"瓶颈"模块
- 只训练Adapter，冻结原始模型

**架构:**
```
输入(d维) 
  ↓
下投影(d → m)  # m << d，如m=64
  ↓
激活函数(ReLU/GELU)
  ↓
上投影(m → d)
  ↓
残差连接
  ↓
输出(d维)
```

**插入位置:**
1. 自注意力之后、残差连接之前
2. 前馈网络之后、残差连接之前

**参数量:**
```
每个Adapter: 2 × d × m
BERT-base (d=768, m=64, 12层, 2个Adapter/层):
  参数量: 2 × 768 × 64 × 12 × 2 ≈ 2.4M
  占比: 2.4M / 110M ≈ 2.2%
```

**优点:**
- ✅ 训练稳定
- ✅ 初始化为恒等映射，不破坏预训练知识
- ✅ 表达能力强于LoRA（参数稍多）

**缺点:**
- ❌ 推理时有额外计算（无法像LoRA那样合并）
- ❌ 参数量比LoRA多

## 4. Prompt Tuning / P-Tuning（提示学习） ⭐⭐⭐⭐

**核心原理:**
- 只训练连续的"软提示"向量
- 冻结整个预训练模型

### 4.1 Prompt Tuning（最简单）
```
传统输入: [CLS] I love this movie [SEP]
Prompt Tuning: [P1] [P2] [P3] ... [Pk] I love this movie [SEP]
                ↑    ↑    ↑          ↑
            可学习的软提示（连续向量）
```

**参数量:**
```
假设: 提示长度=20, 隐藏维度=768
参数量: 20 × 768 = 15,360
占比: 15K / 110M ≈ 0.014%
```

### 4.2 P-Tuning v1（使用编码器）
- 使用BiLSTM/MLP编码提示
- 训练更稳定
- 可插入到序列任意位置

### 4.3 Prefix Tuning（在每层添加前缀）
- 在每个Transformer层的K、V前添加可学习前缀
- 参数量稍多，但效果更好
- 特别适合生成任务

**优点:**
- ✅ 参数极少（<0.1%）
- ✅ 对超大模型特别有效（>10B参数）
- ✅ 支持多任务（每个任务一组提示）

**缺点:**
- ❌ 小模型上效果不如LoRA/Adapter
- ❌ 训练需要更多技巧（初始化、学习率等）

---

## 5. 选择建议

**场景1: 通用微调任务（推荐）**
- 首选：**LoRA** (rank=8或16)
- 理由：参数少、效果好、易用

**场景2: 需要更强表达能力**
- 选择：**Adapter** (bottleneck_dim=64)
- 理由：参数稍多但表达能力更强

**场景3: 超大模型微调（>10B）**
- 选择：**Prompt Tuning** 或 **Prefix Tuning**
- 理由：参数极少，显存占用低

**场景4: 多任务学习**
- 选择：**LoRA** 或 **Prompt Tuning**
- 理由：支持任务切换
