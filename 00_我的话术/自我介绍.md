# 自我介绍

## 1 分钟版（HR / 初筛）

> "我叫李永琪，大连民族大学计算机技术硕士，研究方向是视频行为识别，发过两篇 CCF-C。2025 年初开始转大模型应用：先在 Nestflo 从 0 到 1 做房产智能客服 Agent，服务 1k+ 用户、减少约 80% 简单问题人工；现在在杭州超节点做数学科研 Agent 平台和多模型 AI 网关，完整经历了平台三代架构演进，服务公司和浙大、南大等高校。方向是 Agent 应用开发，既能啃底层工程，也关心业务结果。"

## 3 分钟版（技术 / 业务面）

在 1 分钟版基础上展开：

> 我硕士做 CV 时发现学术界做的模型很难真正落到业务里，2025 年初大模型应用爆发，我想做能直接产生用户价值的事，就主动转了。
> 第一段在 Nestflo 做房产客服 Agent，从租前咨询到租后支持的多 Agent 平台，难点不是搭模型，而是怎么把 "用户问题 → 意图识别 → 路由 → 答复" 拆成稳定链路，再用语音识别和情感分析做售后质检。最后服务 1k+ 用户，简单问题人工处理降了 80%。
> 第二段在超节点，做面向数学研究的 AI for Science 平台。这个项目最大的特点是我跟着它走过三代：第一代基于 Agno 做多 Agent 编排和 RAG 记忆；第二代把能力重构成可复用 Skill，加了多角色群体研讨和人在回路；第三代迁到 Codex Harness/MCP 通用执行底座，打通 GPT-5.6 + Codex + Lean4 形式化证明链路。同时我还负责了一个生产级多模型网关，Go 写的，15 天扛了 31.2 万请求、拦截 3.1 万次恶意扫描。
> 我觉得自己的特点是技术深度和业务 sense 都有一点：能写架构、做网关，也关心降本增效这种实际结果。
