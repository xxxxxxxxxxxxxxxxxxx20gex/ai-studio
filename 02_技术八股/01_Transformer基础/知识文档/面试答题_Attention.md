## Q1: 手写Attention公式并解释每个部分

**标准公式：**

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) · V
```

**逐步拆解：**

1️⃣ **QK^T：计算查询和键的相似度**

```text
Q: (seq_len, d_k) - 查询矩阵
K: (seq_len, d_k) - 键矩阵

QK^T: (seq_len, seq_len) - 相似度矩阵

例如: "我 爱 中国" (3个词)
QK^T = [
  [s11, s12, s13],  # "我" 对所有词的相似度
  [s21, s22, s23],  # "爱" 对所有词的相似度
  [s31, s32, s33]   # "中国" 对所有词的相似度
]
```

2️⃣ **/ sqrt(d_k)：缩放因子**

```text
防止点积结果随维度增大而过大，softmax 后变成几乎 one-hot，
导致梯度非常小，训练不稳定。
```

3️⃣ **softmax(...)：归一化为概率分布**

```text
每一行和为 1，表示注意力权重分配：
[s11, s12, s13] → softmax → [0.2, 0.3, 0.5]
```

4️⃣ **× V：用注意力权重加权求和值向量**

```text
V: (seq_len, d_v) - 值矩阵
输出: (seq_len, d_v) - 融合上下文后的表示

例："爱" 的新表示 = 0.2×V(我) + 0.3×V(爱) + 0.5×V(中国)
```

## Q2: 为什么要除以 sqrt(d_k)？

**核心答案：** 防止点积结果过大，softmax 变得过于「尖锐」，导致梯度消失。

**详细解释：**

1. **从方差角度：**

假设 Q、K 的各维是均值 0、方差 1 的独立随机变量：

```text
点积 = q · k = q₁k₁ + q₂k₂ + ... + q_{d_k}k_{d_k}

E[q · k] = 0
Var[q · k] = d_k   # 方差随维度线性增长
```

当 d_k 很大时，点积的绝对值会越来越大。

2. **softmax 的问题：**

```text
示意：
小尺度：softmax([10, 8, 6])  ≈ [0.84, 0.11, 0.05]
大尺度：softmax([50, 40, 30]) ≈ [0.9999, 0.0001, 0.0000]

→ 后者几乎是 one-hot，梯度几乎为 0，训练难以更新。
```

3. **缩放的效果：**

```text
除以 sqrt(d_k) 后：

Var[q · k / sqrt(d_k)] = Var[q · k] / d_k = 1

也就是无论 d_k 多大，分布尺度都被稳定到一个合理范围，softmax 更平滑。
```

**一句话总结：**  
> 「除以 `sqrt(d_k)` 是为了做归一化，让不同维度下点积的数值规模保持一致，避免 softmax 过度「一边倒」，保证梯度稳定。」

## Q3: Q、K、V分别代表什么？为什么要分三个？

**类比解释（搜索引擎）：**

```text
Q (Query):   你的搜索词，例如 "如何学习 Transformer"
K (Key):     每个文档的标题/关键字
V (Value):   每个文档的实际内容

过程：
1. 用 Query 和每个 Key 算相似度 → 匹配分数
2. 对分数做 softmax → 得到权重
3. 用权重对 Value 加权求和 → 生成最终回答
```

**在句子中的含义：**

```text
输入: "我 爱 中国"

当计算 "爱" 的新表示时：
Q("爱"): "爱" 想要查什么？
K("我","爱","中国"): 每个词「可以被查到」的特征
V("我","爱","中国"): 每个词实际要被加权汇总的内容
```

**为什么要分三套矩阵？**

1. 如果只用同一个矩阵 X：

```text
Attention(X, X, X) = softmax(XX^T / sqrt(d)) · X
```

只能在一个空间里做自注意力，表达能力受限。

2. 使用独立的 Q/K/V 空间：

```text
Q = X·W_Q  # 决定“我要查什么”
K = X·W_K  # 决定“别人如何被我查到”
V = X·W_V  # 决定“被查到时贡献什么信息”
```

这样：
- 相似度计算发生在 Q/K 空间；
- 输出发生在 V 空间，灵活性更强。

## Q4: Multi-Head 的优势是什么？

**核心答案：** 在多个子空间并行关注不同的关系模式，提高表达能力和稳定性。

**数学角度：**

```text
单头：一个 512 维的注意力空间
多头 (h=8)：8 个 64 维子空间

每个头：
  head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)

最后：
  MultiHead = Concat(head_1, ..., head_8) · W^O
```

**直观角度：**

```text
不同头可以学习不同模式：
Head 1: 关注局部相邻词
Head 2: 关注主语-谓语关系
Head 3: 关注长距离依赖
Head 4: 关注实体之间的关系
...
```

**可视化证据：**

> 「在分析 BERT 的注意力头时，研究者发现：
> - 有的头主要连相邻单词（local pattern）；  
> - 有的头主要连主语和谓语（syntax）；  
> - 有的头主要关注特殊符号，如 `[CLS]`、句号等。  
> 这说明多头确实在学不同的东西。」

**类比总结：**

> 「可以把 Multi-Head 理解成 CNN 里的多通道卷积核：  
> 每个 Attention 头像一个卷积核，从不同角度提取句子的特征，最后把所有特征拼在一起。」
