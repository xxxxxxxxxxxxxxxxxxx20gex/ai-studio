# 经典损失函数理论速查 ⭐⭐⭐⭐

> 💡 本文档为快速复习使用，代码实现请参考 `loss_functions.py`

## 1. 分类任务损失函数

### 交叉熵损失（Cross Entropy Loss）

**公式:**
```
L = -Σ y_true * log(y_pred)
```

**特点:**
- 最常用的分类损失函数
- 结合softmax使用
- 优化目标是最大化正确类别的概率

**应用场景:**
- 多分类任务（图像分类、文本分类）
- 语言模型的token预测
- 序列标注任务

### Focal Loss

**核心思想:**
- 解决类别不平衡问题
- 降低易分类样本的权重，聚焦于难分类样本

**公式:**
```
FL = -α * (1 - p_t)^γ * log(p_t)
```
- γ (gamma): 聚焦参数，通常取2
- α (alpha): 平衡因子，通常取0.25
- p_t: 目标类别的预测概率

**应用场景:**
- 目标检测（RetinaNet首次提出）
- 医疗诊断（罕见病检测）
- 欺诈检测（异常样本少）

## 2. 回归任务损失函数

### 均方误差（MSE, Mean Squared Error）

**公式:**
```
L = (1/n) * Σ (y_pred - y_true)²
```

**特点:**
- 对异常值敏感
- 可导，优化方便

**应用场景:**
- 房价预测、温度预测等回归任务
- 图像重建（自编码器）
- 时间序列预测

### 平均绝对误差（MAE, Mean Absolute Error）

**公式:**
```
L = (1/n) * Σ |y_pred - y_true|
```

**特点:**
- 对异常值不敏感（相比MSE）
- 更robust的损失函数

---

## 3. 对比学习损失函数

### Contrastive Loss（对比损失）

**核心思想:**
- 拉近相似样本的距离
- 推远不相似样本的距离

**公式:**
```
L = (1-y) * 0.5 * D² + y * 0.5 * max(0, margin - D)²
```
- D: 两个样本的欧氏距离
- y: 相似性标签（1=相似，0=不相似）
- margin: 边界值

**应用场景:**
- 人脸识别/验证
- 图像检索
- 签名验证

### Triplet Loss（三元组损失）

**核心思想:**
- 使用三元组（anchor, positive, negative）
- Anchor应更接近Positive，远离Negative

**公式:**
```
L = max(0, D(a,p) - D(a,n) + margin)
```
- a: 锚点样本
- p: 正样本（与anchor同类）
- n: 负样本（与anchor不同类）

**应用场景:**
- FaceNet人脸识别
- 图像检索排序
- 推荐系统
